# Orión — landing page conceptual

Landing page bilingüe (español e inglés) para el concepto Orión, una propuesta universitaria relacionada con acceso a experiencias espaciales. El sitio organiza la presentación en portada, propuesta, hoja de ruta y contacto.

## Tecnologías

- Next.js 15 y React 19
- TypeScript
- Tailwind CSS 4
- i18next para las traducciones

## Desarrollo local

Se requiere Node.js compatible con Next.js 15.

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`. Los comandos `npm run build` y `npm start` preparan y sirven la versión de producción.

## Alcance

Es un prototipo de interfaz. La suscripción al boletín, el correo y la dirección que aparecen en la maqueta no están conectados a servicios reales; reemplázalos o conéctalos antes de presentar el sitio como producto desplegado. El concepto y su hoja de ruta son material de demostración, no una oferta comercial o de inversión.
